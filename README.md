# Anon Player

浏览器里的扫雷录像播放器。支持本地 EVF、AVF、MVF、RMV 文件和 OpenMS 在线录像，提供统一可编辑计数器、命名音效配置与带背景音乐的 MP4 导出。录像和用户音频都在浏览器里处理。

## 本地运行

```sh
npm ci
npm run dev
```

访问终端给出的地址，在中央播放区选择本地录像、拖入文件，或点击「打开 OpenMS 录像」输入录像 ID（如 `107`）或 [OpenMS 录像链接](https://openms.top/#/video/107)。加载后可直接使用播放器控件，通过顶部「导入录像」或拖放更换本地录像。

「导出 MP4」可把多局本地或 OpenMS 录像合成一个视频。列表可排序，每局可设置末帧停留时间，并可为整条视频选择背景音乐和音量。预计总时长包含为完整保留尾音所需的末帧延长。导出使用支持 H.264 和 AAC 编码的浏览器，文件在本机生成，完成后点击「下载 MP4」保存。

视频默认使用 1920×1080、60 fps、10 Mbps。可选用 720p、1080p、1440p、4K 预设，也可独立调整宽度、高度、帧率和视频目标码率。宽高须为正偶数，支持的参数组合取决于浏览器的 H.264 编码能力。

「数据」面板只使用一张计数器表，初始包含 13 行。默认行和新增行均可在表格内修改名称、表达式、排序或删除。「开发者模式」可编辑完整 JSON 数组，每行为 `["名称", "表达式"]`；保存 `[]` 可清空。无效草稿不会替换已保存配置。旧自定义行会自动附加到初始行后，并保留原来的小数精度。

表达式支持数字、字符串、字段、括号及 `+`、`-`、`*`、`/`、`%`、`**`，使用 `||` 拼接显示文本，`roundTo(value, digits)` 舍入并保留 0–6 位小数。例如 `roundTo(100 * bbbv_solved / bbbv, 2) || "%"`。`rtime` 是 `duration` 的别名，表示整局秒数；不可用数值显示 `—`。播放器和 MP4 使用相同的求值与格式规则，导出使用点击生成时已保存配置的快照。

点击「音效」可试听、导入和编排素材，并分别调整总音量、本组音量和每条素材的音量。录像自然播完时播放结束提示音。「配置 → 保存当前配置」可命名保存整套设置及本地音频，切换后修改当前工作设置不会自动覆盖已命名配置；以原名称保存可更新配置，以新名称保存可另存。设置与音频保存在当前浏览器的 IndexedDB 中。

背景音乐下拉框默认「无背景音乐」，最后一项「选择本地音乐」可导入音频。取消或读取失败时保留上一次成功选择的音乐。音乐属于当前导出任务。

## 配置预设

- 在 [src/counters.ts](src/counters.ts) 的 `defaultCounterRows` 修改首次打开时的计数器。每行是 `[名称, 表达式]`。已有浏览器优先读取已保存的配置。
- 在 [src/defaultSoundProfile.ts](src/defaultSoundProfile.ts) 修改「默认配置」。把文件放进 `public/sounds/profiles/default/`，用 `{ id, name, path }` 登记，再把素材 ID 填入组的 `ids`。固定模式使用 `fixedId`，随机模式使用 `random`，顺序模式使用 `sequence`。轮播顺序与 `ids` 一致。音量取值为 0 到 1。
- 在 [src/musicTracks.ts](src/musicTracks.ts) 按下拉框显示顺序登记 `{ id, name, path }`，曲目文件放进 `public/audio/music/`。

音频条目使用唯一的 `id`，`path` 相对于对应素材目录，子目录用 `/` 分隔。默认音效读取或解码失败时回退到内置音效。

## 构建与部署

```sh
npm test
npm run build
npm run preview
```

`build` 先做 Vue 和 TypeScript 类型检查，再输出 `dist/`。`preview` 用来检查构建结果。将 `dist/` 的全部内容交给静态服务器，通过 HTTPS 提供服务。构建采用相对资源路径，支持域名根目录和以 `/` 结尾的子路径。服务器应为 WASM 返回 `application/wasm`，并随构建产物保留第三方许可文件。

实现细节见 [开发文档](开发文档.md)，操作触发和回放验收见 [扫雷鼠标操作规范](扫雷鼠标操作规范.md)。
