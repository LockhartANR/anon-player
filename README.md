# Anon Player

浏览器里的扫雷录像播放器。支持本地 EVF、AVF、MVF、RMV、开源扫雷网左键／标双训练 JSON，以及开源扫雷网在线扫雷录像。提供可编辑计数器、命名音效配置与带背景音乐的 MP4 导出。录像和用户音频都在浏览器里处理。

## 本地运行

使用 Node.js 24。项目运行在浏览器中，无需后端服务。

```sh
npm ci
npm run dev
```

访问终端给出的地址。在播放区或顶栏打开本地录像、开源扫雷网录像，也可直接拖入本地文件。开源扫雷网支持输入 ID（如 `107`）或 [录像链接](https://openms.top/#/video/107)。文件名右侧的「关闭录像」可返回空白播放区。

点击播放器右下角的「加入导出队列」，再用旁边的「打开下一个」继续导入本地文件，下拉箭头可选择开源扫雷网。播放器下方的队列在关闭或更换录像后保留，刷新页面会清空。调整顺序和末帧停留时间后，点击「生成 MP4」并下载。导出需要支持 H.264 和 AAC 编码的浏览器。

队列下方可调整分辨率、帧率、码率和背景音乐。视频默认使用 1920×1080、60 fps、10 Mbps，可选 720p、1080p、1440p、4K 预设。宽高须为正偶数，支持的参数组合取决于浏览器的 H.264 编码能力。背景音乐支持预设和本地文件，取消或读取失败时保留上一次成功选择的音乐。

在「数据」面板可编辑、删除计数器，也可拖动手柄排序，或聚焦手柄后按上下方向键。「开发者模式」可批量编辑 `["名称", "表达式"]` 数组，保存 `[]` 可清空。「恢复默认计数器」会替换当前列表和顺序。播放器和 MP4 共用计数器配置。

## 小游戏 JSON 录像

支持左键训练的初／中／高级及三种雷密度，以及标双训练的初／中级。可使用原站 v1 录像和旧版 v0 录像；提供原站规则的棋盘变化、按压预览、鼠标及点击标记、剩余计数、进度拖动和倍速。小游戏可与普通扫雷录像一起加入队列导出 MP4。

可直接导入自动构造的 [左键训练示例](examples/left-click.json) 和 [标双训练示例](examples/flag-chord.json)。

每个 JSON 文件包含一局录像。推荐保留 `game`、`rankingKey`、`scoreMs` 和完整的 `replay`；也可用原站的 `mode` 对象描述模式。如果导出工具把多局放在 `records` 数组里，可把其中一条记录另存为 JSON 后导入。

导入只有 `replay` 内容的 JSON 时，播放器会提示补全游戏、模式和总时长。时长初值按最后事件估算，请核对原成绩。原站的 7z 存储归档需先提取 JSON。

训练计数器单独保存，切换回普通录像时恢复原计数器。左键训练使用半透明雷显示；训练录像不提供 3BV 等普通扫雷统计。

表达式支持数字、字符串、字段、括号及 `+`、`-`、`*`、`/`、`%`、`**`。用 `||` 拼接文本，用 `roundTo(value, digits)` 保留 0–6 位小数，例如 `roundTo(100 * bbbv_solved / bbbv, 2) || "%"`。

在「音效」面板选定分组后，可试听并多选预设，或批量导入本地文件。「重试预设导入」会恢复原分组和待导入的预设。素材可排序，总音量、组音量和单条音量可分别调整，录像自然播完时播放结束提示音。音效及设置可命名保存。「恢复默认音效」会将当前工作设置换成项目预设，已命名的配置可继续使用。

## 配置预设

- 在 [src/counters.ts](src/counters.ts) 的 `defaultCounterRows` 修改首次打开时的计数器。每行是 `[名称, 表达式]`。已有浏览器优先读取已保存的配置。
- 将预设音效放进 `public/sounds/profiles/default/`，在 [src/soundPresets.ts](src/soundPresets.ts) 用 `{ id, name, path }` 登记。在 [src/defaultSoundProfile.ts](src/defaultSoundProfile.ts) 为默认配置选择各组素材及播放方式。`fixed` 固定播放首个素材，`random` 随机播放，`sequence` 按列表顺序轮播。音量取值为 0 到 1。
- 在 [src/musicTracks.ts](src/musicTracks.ts) 按下拉框显示顺序登记 `{ id, name, path }`，曲目文件放进 `public/audio/music/`。

音频条目使用唯一的 `id`，`path` 相对于对应素材目录，子目录用 `/` 分隔。默认音效读取或解码失败时回退到内置音效。

## 构建与部署

```sh
npm test
npm run build
```

`build` 检查 Vue 和 TypeScript 类型后输出 `dist/`。通过 HTTPS 提供该目录的全部内容，WASM 应返回 `application/wasm`。构建采用相对资源路径，支持域名根目录和以 `/` 结尾的子路径。

实现细节见 [开发文档](开发文档.md)，操作触发和回放验收见 [扫雷鼠标操作规范](扫雷鼠标操作规范.md)。

## 浏览器回归

构建后，安装测试用的 Chromium 并启动预览：

```sh
npx playwright install chromium
npm run preview -- --host 127.0.0.1 --port 4190 --strictPort
```

在另一终端运行 `npm run test:browser`，检查小游戏导入与回放、MP4 导出、计数器布局、无障碍与排序、音效配置事务及背景音乐取消。可用 `ANON_PLAYER_CHROMIUM` 指定浏览器可执行文件，用 `ANON_PLAYER_URL` 覆盖预览地址。
